# MOTION LAYER — Saga design preview

모션레이어 의류 브랜드의 첫 번째 디자인 시안입니다. Saga의 여백, 글자 메뉴, 상품 중심 배치를 참고하여 별도로 구현한 정적 프로토타입입니다. 유료 Shopify 테마 파일이나 소스 코드를 사용하지 않았습니다.

## 실행

Node.js가 설치된 환경에서:

```powershell
npm run dev
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 의존성 설치나 빌드 과정은 필요하지 않습니다.

## 구현한 범위

- PC·모바일 메인, 상품 그리드와 번호형 Index 보기
- 아이템·컬러·상태·시리즈 필터, 검색 및 정렬
- 상품 상세, 옵션 선택, 예시 사이즈표, 소재·세탁·배송 정보 영역
- 브라우저에 저장되는 장바구니, 수량 조절, 삭제, 주문 미리보기
- 브랜드 소개와 점 로고 이야기, FAQ·고객 안내, 구독 화면
- 비공개 Sites 미리보기

## 시안용 콘텐츠

상품 사진은 gnuhr의 공개 사이트에서 가져온 임시 참고 사진입니다. 실제 모션레이어 상품이 아니며, 상품명·가격·사이즈·설명 역시 화면 확인을 위한 예시입니다. 이미지 출처는 `asset-sources.json`에 기록되어 있습니다. 정식 운영 전에 브랜드가 사용 권한을 가진 실제 상품 이미지와 확정된 정보로 교체해야 합니다.

결제, 회원 가입, 간편결제, 적립금·쿠폰, 이지어드민, 인스타그램 API 및 이메일 발송은 연결하지 않았습니다. 실제 주문이나 개인정보 전송은 발생하지 않습니다. 카페24 단계에서는 해당 기능을 실제 상품·주문 모듈에 연결해야 합니다.

## 구성

- `dist/`: 배포할 사이트. HTML·CSS·JavaScript와 로컬 이미지
- `tools/serve.mjs`: 로컬 미리보기 서버
- `tools/fetch_assets.py`: 참고 사진 다운로드 및 WebP 변환 도구
- `.openai/hosting.json`: 비공개 사이트 식별자와 정적 배포 설정

디자인 참고: https://themes.shopify.com/themes/space/presets/saga

실제 데모의 모션을 다시 관찰해 화보 확대·이미지 로딩 전환·고정 헤더·메뉴와 장바구니 전환을 보완했습니다. [MOTION-AUDIT.md](MOTION-AUDIT.md)에 동작과 확인 범위를 기록했습니다.

`#brand-film`은 추가한 와이드 영상 구간입니다. Cascade 시안의 영상과 포스터를 동일한 파일로 재사용합니다. 음소거 미리보기에서 Play를 누르면 처음부터 재생하고 기본 영상 조작 버튼이 나타납니다. OS 모션 줄이기 설정에서는 자동 재생과 비필수 전환을 중단합니다.
