# Saga 모션 비교 및 반영

참조: [Shopify Saga](https://themes.shopify.com/themes/space/presets/saga)에서 연결되는 [현재 실제 데모](https://spacethemedemo5.myshopify.com/). 현재 데모의 브랜드 표기는 Shift입니다. 데스크톱 1440×1000, 모바일 390×844에서 마우스 이동·클릭·스크롤로 확인했습니다. 시안 검증은 375·390·430px 모바일 화면도 포함합니다. 실물 휴대전화에서의 검증을 뜻하지 않습니다.

| 대상 | 실제 데모에서 확인한 동작 | Saga 시안 반영 |
| --- | --- | --- |
| 상품 사진 | 홈페이지 상품 16개 중 13개는 카드 전체에 포인터를 올리면 두 번째 사진이 300ms 동안 겹쳐 나타남. 상품명 위에서도 유지되고 카드를 벗어나면 같은 속도로 복귀. 첫 상품은 앞면 한 장만 보유 | 시안의 아홉 상품에 같은 상품·색상의 뒷면 촬영 컷을 연결. 그리드와 번호형 Index에서 300ms `cubic-bezier(.4,0,.2,1)`로 전환 |
| 화보 | 이미지 틀 안에서 1 → 1.05 확대, 1000ms `cubic-bezier(.4,0,.2,1)` | 상품 목록 다섯 번째 아이템 다음 화보 구간을 추가하고 같은 확대·복귀 적용 |
| 이미지 로딩 | 저해상도 흐림 이미지가 준비된 사진 위에서 1000ms 동안 사라짐. 로딩 확인 후 50ms 지연 | 로컬 이미지 기반 흐림 레이어와 1000ms 페이드 구현. 필터와 상품 상세에서도 처리 |
| 헤더 | 스크롤 중 상단 유지, `mix-blend-difference`로 배경 위에 겹침 | 고정 헤더 및 같은 배경 혼합 방식 |
| 영상 기본 상태 | 큰 와이드 영상이 음소거·반복 재생되고 중앙에 Play 버튼 | 같은 구간과 버튼 추가. 화면 밖·비활성 탭에서는 일시정지 |
| 영상 Play | 현재 시간을 0으로 되돌리고 재생, controls를 켜며 muted를 해제. Play 버튼은 사라짐 | 같은 동작. 별도의 팝업이나 전체 화면 강제 전환 없음 |
| 영상 비율 | 약 1.771:1. 모바일 390px에서 높이 약 220.2px | 같은 비율을 사용. Cascade의 세로 전체 화면 레이아웃과 구분 |
| PC 장바구니 | 오른쪽 패널 위치, 300ms opacity 전환 정의 | 기존 오른쪽 장바구니에 300ms 페이드 및 닫기 전환 |
| 모바일 메뉴·장바구니 | 화면 아래에서 95svh 패널이 올라옴. 300ms translateY + opacity 정의 | 같은 방향·높이·시간으로 구현. ESC와 바깥 클릭 지원 |
| 모달 배경 | 검정 20–40% 그라데이션, 흐림, 300ms 페이드 | 같은 구성 |
| 모바일 상품 | 한 줄에 상품 하나가 이어짐 | 한 열 구성으로 조정. 메뉴·브랜드·장바구니 헤더 배치도 조정 |
| 모션 줄이기 | 시안의 비필수 움직임을 중단해야 하는 운영 조건 | 확대·흐림 전환·패널 애니메이션 및 자동 재생 중단. 사용자가 누른 Play는 작동 |

화보의 실제 확대값은 호버 뒤 100ms에 1.0013, 350ms에 1.0270, 700ms에 1.0477, 1100ms에 1.05로 기록됐습니다. 영상은 처음에 `paused:false`, `muted:true`, `controls:false`였고, Play를 누른 뒤 `muted:false`, `controls:true`, 현재 시간 약 0.45초로 확인했습니다. 원본 페이지의 공개 코드 전체를 복제하거나 유료 테마 파일을 설치하지 않고 동작을 독립적으로 구현했습니다.

원본의 Classic Logo Pink에 마우스를 올렸을 때 뒷면의 불투명도는 60ms에 약 0.18, 140ms에 약 0.84, 종료 후 1이었습니다. 상품명으로 옮겨도 1을 유지했고 카드 밖에서는 0으로 돌아왔습니다. 시안의 티셔츠·아우터·팬츠·가방은 제품 뒷면 컷을 사용했고, 모자는 뒤쪽 조절끈이 보이는 착용 컷을 사용했습니다. 뒷면 로딩이 끝나기 전에는 앞면이 보입니다. 키보드 포커스에서도 뒷면을 볼 수 있고, 터치 화면은 한 번 탭하면 상세가 열립니다.

## 영상 재사용

사용자 요청대로 새 영상은 다운로드하지 않았습니다. `motionlayer-cascade/dist/assets/lookbook.mp4`와 `lookbook-poster.webp`를 Saga 시안 안으로 복사했습니다. 각각의 SHA-256이 원본 파일과 일치함을 확인했고 출처·해시를 `asset-sources.json`에 기록했습니다. 영상 내용은 Cascade 시안의 임시 촬영 영상이며 원본 Saga의 스케이트 영상과는 다릅니다.

## 유지한 시안 기능과 검증

모션레이어의 브랜딩, 번호형 Index 보기, 상태·아이템·컬러·시리즈 필터, 검색·정렬, 옵션 선택, 브라우저 장바구니와 주문 미리보기는 기존 시안 기능을 유지했습니다. 원본에 없는 기능에 적용한 팝업·검색·상태 패널의 전환은 Saga의 300ms 모션 토큰에 맞춘 시안 조정입니다. 결제나 외부 전송은 연결하지 않았습니다.

`tools/local_qa.py`가 실제 입력으로 화보 확대·복귀, 영상 자동·수동 재생, 패널 중간 상태·ESC·포커스 복귀, 기존 상품·필터·장바구니와 세 모바일 폭을 검사합니다. `.qa/reference/`의 참조 페이지·번들·캡처는 관찰용이며 배포에 포함되지 않습니다. 영상은 `#brand-film`으로 바로 볼 수 있습니다.

`preserved-sites.json`은 이번 작업 시작 시 Cascade와 여성복 시안의 주요 파일 해시를 기록합니다. 게시 전 동일성을 확인해 다른 두 시안이 변경되지 않았음을 검증합니다.
