# MOTION LAYER · Garment Index

모션레이어의 네 번째 독립 디자인 시안. Field Studies 화보에서 시리즈를 열거나 사진과 번호 목록을 함께 탐색할 수 있습니다. 기존 모션레이어 점 로고를 사용했습니다.

## 화면과 조작

- PC 첫 방문에는 화보와 활자가 차례로 드러납니다. 휴대폰에서는 점 로고가 있는 표지가 짧게 열린 뒤 화보가 나타납니다. 세션당 한 번 재생하며 `?intro=1`에서 다시 볼 수 있습니다. 기기의 모션 줄이기 설정을 따릅니다.
- 사진이나 상품명에 마우스를 올리면 두 목차의 같은 번호가 함께 강조됩니다. 다른 사진은 500ms 동안 불투명도 0.1로 바뀝니다. 선택한 상품의 뒷면이 300ms에 걸쳐 나타납니다. 키보드로 탐색해도 같은 상품이 강조됩니다.
- 모바일에서는 큰 사진 아래에 번호 목록이 이어집니다. 목록을 스크롤하면 상단 사진이 따라 바뀌며 앞면·뒷면을 직접 선택할 수 있습니다. 상품 상세에서는 좌우 스와이프와 사진 선택 버튼을 지원합니다.
- 상태 선택은 PC의 인라인 선택지와 모바일 전용 화면으로 구성했습니다. 상태·상품 종류·컬러·시리즈·정렬은 주소에 보존됩니다.
- 사이즈 안내, 소재·세탁, 품절, 장바구니, 결제 수단 미리보기, 회원·주문 안내와 스튜디오 피드 배치가 포함되어 있습니다. 장바구니는 브라우저에 저장됩니다. 상품 정보는 예시이며 카페24·결제·이지어드민·인스타그램 API는 연결 전 단계입니다.

## 참고와 사진

[gnuhr](https://www.gnuhr.com/)에서 PC의 사진·상품명 교차 호버와 복귀, 글자 메뉴, 모바일 첫 화면과 상품 탭을 확인했습니다. [OEM](https://oem.care/collections/all)에서는 PC·모바일 모두 상태 선택을 조작했습니다. Stressed 선택 시 주소의 필터 값이 `stress`로 바뀌며 목록이 갱신됩니다. 시안의 네 가지 상태와 의류 추천 조합은 모션레이어용입니다.

필드 시리즈 첫 화보는 내장 ImageGen으로 제작했습니다. 최종 프롬프트와 나머지 임시 제품 사진의 출처는 [asset-sources.json](asset-sources.json)에 있습니다. 프런트엔드는 로컬 이미지와 폰트를 사용합니다.

## 로컬 확인

`npm run dev`로 4197 포트에 정적 미리보기를 엽니다. Windows의 Chrome 환경에서 `python -X utf8 tools/check_preview.py`로 데스크톱 및 360·390·430px 터치 화면을 검사할 수 있습니다. 검사에는 Python Playwright와 Pillow가 필요합니다.
