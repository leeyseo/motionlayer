# MOTION LAYER — The soft edit

기존 `motionlayer-saga`를 그대로 보존하고 별도 폴더·별도 비공개 사이트로 만든 여성복 디자인 시안입니다.

부드러운 세리프 타이포그래피, 여성복 착용 화보, 여유 있는 상품 간격과 비대칭 갤러리 배치를 적용했습니다. 서버 연동 없이 화면 형태를 검토하는 정적 프로토타입입니다.

```powershell
npm run dev
```

http://127.0.0.1:4173 에서 로컬 확인이 가능합니다. 별도 패키지 설치나 빌드는 필요하지 않습니다.

사진은 Cascade의 공개 데모에서 가져온 임시 참고 사진입니다. 실제 모션레이어 상품이 아니며 이름·가격·설명도 시안용입니다. 출처는 `asset-sources.json`에 기록했습니다. 정식 운영 시 사용 권한이 있는 브랜드 사진과 확정된 상품 정보로 교체해야 합니다. Shopify 테마의 소스 코드는 사용하지 않았습니다.

기능은 갤러리·번호형 목록 전환, 간단한 분류·컬러·기분 필터와 상품 상세 미리보기로 한정했습니다. 장바구니·회원·주문·결제·개인정보 수집·이지어드민·인스타그램·이메일 발송은 연결하지 않았습니다.
