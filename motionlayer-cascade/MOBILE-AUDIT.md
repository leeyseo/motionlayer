# Cascade 모바일 화면 비교

참조: [공식 Cascade 데모](https://cascade-preset-1.myshopify.com/). 모바일 Chrome 에뮬레이션에서 직접 메뉴·사진·캐러셀을 조작하고 DOM 크기를 측정했습니다. 검증 폭은 375·390·430px입니다. 실물 휴대전화 검증을 의미하지 않습니다.

기존 시안은 작은 화보와 캡션, 78px 헤더 등 독자적인 축소 레이아웃이어서 데모의 모바일 구성이 달랐습니다. 이번 변경은 데스크톱을 줄이는 방식 대신 원본의 모바일 흐름을 따릅니다. 브랜드명과 점 로고, 상품명·가격·문구는 모션레이어 시안 콘텐츠를 유지합니다.

| 항목 | 원본 모바일 관찰 | 시안 반영 |
| --- | --- | --- |
| 헤더 | 높이 56px, Menu 왼쪽·브랜드 중앙·Cart 오른쪽. 스크롤 중 사진 위로 겹치는 투명 배경 | 같은 높이·순서·배경. 중앙 브랜드명은 MOTION LAYER |
| 첫 화보 | 390px 화면에서 x 0, y 136, 폭 325px | x 0, y 136, 폭 325px |
| 두 번째 화보 | 오른쪽 정렬 x 65, 폭 325px, 첫 사진 아래 154px | 같은 폭·정렬·간격 |
| 세 번째 화보 | 왼쪽 가로 사진, 폭 325px, 자연 비율 | 기존의 4:3 크롭을 해제하고 자연 비율 사용 |
| 네 번째 화보 | 오른쪽 블루 셋업 사진, 폭 325px | 빠졌던 네 번째 사진 추가 |
| 화보 흐름 | 4장 모두 화면 폭의 5/6, 좌·우·좌·우. 사진 사이 154px | 네 장을 실제 문서 흐름에 배치. 고정 top 값 제거 |
| 사진 캡션 | 모바일 화보 아래 별도 캡션이 없음 | 작은 캡션을 제거하고 이미지 중심 구성 |
| 브랜드 소개 | 화보 다음 중앙 정렬 큰 문단, 약 28px 글자와 위아래 40px | 같은 크기·정렬·패딩으로 모션레이어 소개 표시 |
| Latest Arrivals | 24px 중앙 고정 제목, 콘텐츠 폭의 5/6인 8개 상품이 좌우 교차 | 기존 고정 제목을 유지하고 홈 순서에 연결 |
| 첫 캐러셀 | Latest Arrivals 다음에 위치. 사진 앞에 제목·설명·둥근 View all 버튼 | 추가 카탈로그가 흐름을 가로막지 않도록 Shop으로 이동 |
| 캐러셀 사진 | 슬라이드 폭 75vw, 좌우 내부 여백 20px. 390px에서 실제 사진 폭 252.5px | 같은 수치. 상품명·가격은 16px |
| 캐러셀 조작 | 한 상품씩 600ms, 다음 상품 일부가 보이며 터치 드래그 | 같은 이동량·속도. 끝 저항과 되돌아오기 유지 |
| 배경 영상 | 높이 100vh, 가운데 제목 약 29px, 버튼 16px | 100svh 및 작은 중앙 제목·둥근 버튼 |
| 흐르는 문구 | 높이 약 50px, 글자 약 24px | 24px·상하 8px, 모션 줄이기 지원 |
| 모바일 메뉴 | 왼쪽 패널, 왼쪽 위 닫기, 24px Shop/Lookbook 등과 아래 검색선 | 같은 배치와 #f8f7f5 배경. 카테고리는 Shop 아래 접힘 |
| 상품 상세 사진 | 사진이 75vw 슬라이드 안에서 좌우 20px 여백을 가지고 다음 컷이 보임 | 전체 화면 미리보기 안에서 같은 사진 폭과 원래 비율, Prev/Next·스와이프 |
| 본문·가격 | 기본 글자 16px | 기존의 7–13px 축소 글자를 주요 영역에서 16px로 조정 |

390px에서 시안의 네 화보 top은 136 / 783.58 / 1425.08 / 1795.73px입니다. 원본 측정값 136 / 783.95 / 1425.45 / 1796.42px와의 차이는 다운로드 이미지의 자연 비율 차이에 따른 1px 미만입니다. 소개 문단 끝까지의 위치도 원본 약 2583.02px, 시안 약 2582.95px입니다.

원본에는 모션레이어의 오늘의 기분 필터·회원 기능 요구사항 등이 없으므로 해당 콘텐츠는 시안에 유지합니다. 상품 상세는 원본의 독립 상품 페이지 대신 기존의 미리보기 창을 유지하면서 모바일 사진·서체·조작을 맞췄습니다. 전체 사이트의 문구나 모든 후반 섹션을 동일하게 복제했다는 의미는 아닙니다.

원본 캡처는 `.qa/reference/mobile-reference-*`, 수정 결과는 `.qa/motion/mobile-*`에 저장됩니다. `tools/motion_check.py`는 원본에서 측정한 헤더·사진·간격·캐러셀 치수를 세 화면 폭에서 확인하고, 모바일 Shop 진입·홈 복귀·갤러리와 캐러셀 터치를 검사합니다.
