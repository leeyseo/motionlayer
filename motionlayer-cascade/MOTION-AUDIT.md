# Cascade 실동작 관찰 및 시안 반영 기록

관찰일: 2026-11-20. [공식 테마 소개](https://themes.shopify.com/themes/cascade/presets/cascade)에서 연결되는 [실제 Cascade 데모](https://cascade-preset-1.myshopify.com/)를 확인했습니다. 관찰 대상은 해당 데모의 현재 설정입니다. 다른 프리셋이나 관리자에서 선택 가능한 모든 옵션을 뜻하지 않습니다.

홈 전체, `/collections/all`, `/products/vinho-dress-navy`, 메뉴, 검색, 빈 장바구니, 필터를 살펴봤습니다. Chrome 데스크톱 1440×1000 및 모바일 390×844 에뮬레이션에서 실제 마우스 이동·클릭·스크롤을 보냈습니다. 터치 스와이프는 구현 시안에서도 별도로 검증했습니다. 실물 휴대전화 검증은 포함하지 않습니다.

전환 도중의 computed style과 Web Animations 정보를 함께 기록했습니다. 예를 들어 첫 화보의 확대는 80ms 시점 약 1.046, 200ms 약 1.095, 완료 시 1.1이었습니다. 화면 캡처 한 장을 보고 추정한 값이 아닙니다. 원본 테마 파일을 설치하거나 번들을 복제하지 않고 관찰된 동작을 독립적으로 구현했습니다.

## 시차와 반복 문구의 세부 수치

데모의 시차 강도 설정은 50이며 실효 계수는 .555였습니다. 진행률은 `(뷰포트 높이 - 요소 top) / (뷰포트 높이 + 요소 높이) - .5`, Y 이동량은 `-.555 × speed × 진행률 × 100px`입니다. 첫 화보의 실제 이동량은 스크롤 0 / 450 / 900px에서 약 -2.76 / -20.38 / -38.58px였습니다. 시안은 사진 크기와 배치가 달라 절대 위치는 달라지며 같은 산식을 적용합니다. 스크롤 관성이나 별도의 부드러운 스크롤 라이브러리는 추가하지 않았습니다.

흐르는 문구는 한 줄 전체 폭에 맞추어 복제됩니다. 데모 관찰 시 전체 반복 주기는 약 73.479초였고, 기본값 19초와 화면·문구 너비 보정이 적용돼 있었습니다. 시안도 `19 × 전체 반복 줄 너비 / 1024`초를 사용해 글자 길이가 달라도 이동 속도를 유지합니다. 호버 뒤 100ms와 500ms의 transform이 같아 실제 정지도 확인했습니다.

## 시안에 맞춘 부분

원본의 상품 사진 클릭은 일반 상품 페이지로 이동합니다. 현재 시안은 기존 상품 미리보기 창을 유지하고, 그 안의 갤러리와 확대 화면에 관찰한 전환을 적용했습니다. 미리보기 창 자체는 관찰한 소형 팝업 방식인 300ms gentle + 75ms 지연을 사용합니다. 페이지를 넘기는 독자적인 커튼·페이드 효과는 만들지 않았습니다.

Flow / Index, 오늘의 기분 추천, 상품 번호, 모션레이어 브랜딩은 기존 요구사항을 유지한 부분입니다. 원본의 네 번째 화보나 모든 상품·카테고리 섹션을 그대로 복사한 구성은 아닙니다. 상품·가격·장바구니는 브라우저 안에서 형태를 검토하는 임시 데이터이고 실제 주문·결제·회원·재고 연동은 없습니다.

## 검증 및 보존

`tools/motion_check.py`는 실제 입력으로 확대의 중간·완료 상태, 원상복귀, 시차, 패널 방향, ESC와 포커스, 검색, 상품 갤러리, 확대, 사이즈 선택, 장바구니 형태, 필터, 모바일 스와이프, 반복 문구, 영상, 모션 줄이기를 확인합니다. 캡처와 실행 결과는 `.qa/motion/`에 저장됩니다.

참조 브라우저의 세부 캡처와 시간별 측정은 `.qa/reference/`에 있습니다. 이 폴더의 원본 페이지·공개 번들은 배포 및 소스 저장 대상에서 제외되어 있습니다. 사진·영상의 임시 출처는 `asset-sources.json`에 기록했습니다.

이전 Saga와 여성복 시안의 HTML·CSS·JS·사이트 식별자 8개 파일은 `original-checksums.json`과 해시를 비교해 보존을 확인했습니다.

## 배경 영상·하단 캐러셀 추가 확인

배경 영상은 19.008초의 영상이며, 데스크톱에서 너비 1425px일 때 높이 801.5625px인 16:9 영역을 채웁니다. 모바일 390×844에서는 영상 영역이 정확히 390×844px입니다. 영상은 `position: absolute`와 `object-fit: cover`로 섹션 뒤쪽을 채우고 제목과 룩북 버튼이 앞에 겹칩니다. 페이지 전체에 고정되는 배경은 아닙니다. 시안도 모바일 100svh로 맞추고 Lookbook 메뉴를 영상에 직접 연결했습니다.

데모에는 영상 위 Coats & Jackets와 아래 Skirts, 두 개의 상품 캐러셀이 있습니다. 아래 캐러셀도 실제 Next 클릭에서 610ms, 모바일에서는 600ms로 측정됐습니다. 시안에는 모션레이어의 임시 상품을 사용한 두 번째 Layers in motion 섹션을 추가하고 각 섹션이 독립적으로 이동하도록 했습니다.

캐러셀은 입력 없이 3초 기다리는 동안 위치가 유지됐고, 별도로 흐르는 문구는 계속 이동했습니다. 마지막 상품에서 터치로 200px 더 밀었을 때, 실제 이동은 약 104px로 저항이 생겼으며 손을 놓은 뒤 600ms 동안 같은 마지막 상품으로 복귀했습니다. 시안에서도 드래그 경계에는 0.5 배율 저항을 적용하고 마지막에서 첫 상품으로 되감기지 않도록 보완했습니다. Next 버튼을 통한 되감기는 유지합니다.

바로 확인할 수 있는 시안 앵커는 배경 영상 `#campaign-film`, 위 캐러셀 `#everyday-edit`, 아래 캐러셀 `#layers-edit`입니다.

## Latest Arrivals 구간 추가 확인

기존의 필터형 상품 목록은 이 구간의 중앙 고정 제목을 표현하지 못했습니다. 화보와 상품 목록 사이에 `#latest-arrivals` 구간을 별도로 추가했습니다. 제목은 섹션 안에서 뷰포트 중앙에 머무르고, 끝에 도달하면 상품과 함께 위로 빠져나갑니다. 제목 레이어는 포인터를 받지 않아 겹쳐지는 사진의 호버·클릭을 유지합니다.

1440×1000 데스크톱 관찰 시 열 사이 간격은 80px, 상품 사이 세로 간격은 238px입니다. 왼쪽 열은 4/12·5/12·10/12·9/12, 오른쪽 열은 9/12·7/12·4/12·5/12 크기로 나타나며 두 열은 서로 독립적으로 아래로 흐릅니다. 오른쪽 첫 상품은 238px 낮게 시작하고, 등장 효과에는 300ms 지연이 있습니다. 상품별 시차 속도는 화면에 나오는 순서대로 1, -3, 2, -2, -2, 3, -3, 2입니다.

모바일 390×844에서는 상품이 한 줄씩 좌우로 번갈아 배치됩니다. 폭은 콘텐츠 영역의 5/6, 세로 여백은 154px이며 제목은 약 24px로 줄어듭니다. 시안도 같은 구성과 순서를 적용했습니다. 사진은 두 번째 촬영 컷으로 200ms 동안 전환되고 클릭하면 해당 상품 미리보기를 엽니다. 추가된 네 상품도 검색과 장바구니 미리보기로 연결됩니다. 모션 줄이기에서는 제목이 일반 문서 흐름으로 이동하고 모든 사진이 즉시 보입니다.
