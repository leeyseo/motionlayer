# MOTION LAYER — Cascade design preview

기존 Saga 시안과 여성복 시안은 보존하고, 별도 폴더와 별도 비공개 사이트로 만든 세 번째 디자인 시안입니다.

Cascade의 큰 타이포그래피, 겹쳐지는 사진, 서로 다른 크기의 이미지를 따라 흐르는 비대칭 배치를 참고해 직접 구현했습니다. 유료 테마 파일과 소스 코드는 사용하지 않았습니다.

```powershell
npm run dev
```

http://127.0.0.1:4173 에서 로컬 미리보기를 볼 수 있습니다. 별도의 패키지 설치나 빌드가 필요하지 않습니다.

화면 형태를 검토하기 위한 프로토타입입니다. 목록·간단한 필터·상품 상세 미리보기만 제공하며 실제 회원·주문·결제·재고 연동은 없습니다. 사진·상품명·가격·설명은 임시 참고 콘텐츠입니다. 사진 출처는 `asset-sources.json`에 기록했습니다. 정식 운영 시 사용 권한이 있는 브랜드 콘텐츠로 교체해야 합니다.

`original-checksums.json`은 작업 시작 시 기존 두 시안의 주요 파일과 사이트 식별자를 기록한 보존 확인 자료입니다.

실제 Cascade 데모의 호버·스크롤·메뉴·상품 갤러리·하단 슬라이더·영상 동작을 관찰한 내용과 반영 범위는 [MOTION-AUDIT.md](MOTION-AUDIT.md)에 기록했습니다. 자바스크립트 라이브러리 없이 CSS 전환, IntersectionObserver, requestAnimationFrame, native dialog로 구현했습니다.

검색·필터·메뉴·장바구니 패널과 상품 촬영 컷 전환은 화면 검토를 위한 로컬 동작입니다. 장바구니는 페이지를 새로 고치면 초기화됩니다. 영상은 화면에 들어오면 재생하고 벗어나면 멈춥니다. OS의 모션 줄이기를 설정하면 영상 자동 재생과 시차·반복 문구가 멈춥니다.

로컬 서버를 4175 포트로 실행한 상태에서 `python tools/motion_check.py`로 데스크톱·모바일 브라우저 검증을 실행할 수 있습니다. 로컬 Chrome과 Python websockets가 필요합니다.

배경 영상은 `#campaign-film`, 영상 아래의 두 번째 상품 캐러셀은 `#layers-edit`로 바로 이동할 수 있습니다. Lookbook 메뉴도 영상으로 연결됩니다. 캐러셀의 Next 버튼은 끝에서 되감기며, 끝을 넘어서는 드래그는 저항을 주고 원래 위치로 돌아옵니다.

`#latest-arrivals`는 화보 다음의 신상품 구간입니다. 중앙에 고정되는 제목과 크기가 다른 8개 상품이 엇갈려 흐르는 배치를 재현했습니다. 모바일에서는 좌우 교차 배치로 바뀝니다. 기존 필터형 상품 목록은 별도로 유지됩니다.

모바일 구성은 원본 데모의 375·390·430px 화면과 비교했습니다. 56px 투명 헤더, 4장 화보의 5/6 폭·154px 간격, 중앙 소개 문단, 캐러셀의 75vw 슬라이드와 16px 상품 글자, 메뉴·영상·상품 갤러리를 반영했습니다. 상세 비교는 [MOBILE-AUDIT.md](MOBILE-AUDIT.md)를 참고하세요.

모바일 홈의 섹션 순서를 위해 필터형 카탈로그는 Shop 메뉴에서 `#collection`으로 열립니다. 브랜드를 누르면 모바일 홈으로 돌아옵니다. 데스크톱 카탈로그는 기존 흐름에 유지됩니다.
